# 箱庭ドローンPRO オプションライセンス

本文書では、箱庭ドローンPROにおけるオプションライセンスについて、以下を規定します。

- ライセンス体系
- 提供形態
- 利用範囲
- 対応する機能およびビルド設定

正式な契約条件、利用許諾範囲、禁止事項、保守条件等は、個別のライセンス文書および契約書にて定義します。

本文書は、利用者および開発者が、箱庭ドローンPROに含まれる各機能について、
「どの機能が、どのライセンスに対応し、どのビルド設定によって有効化されるか」
を確認できるようにすることを目的とします。

## ライセンス体系

| 区分 | 提供形態 | 主な利用範囲 | 備考 |
| --- | --- | --- | --- |
| 箱庭ドローン無償版 | 公開リポジトリおよびバイナリ提供 | 標準機体モデル、標準制御、標準箱庭アダプターの利用 | 外部制御アダプターとの接続機能は無効 |
| 箱庭ドローンPRO | 個別契約に基づく提供 | PRO向け機能、商用利用、契約範囲内での拡張利用 | 提供内容および利用範囲は契約条件に従う |
| 箱庭ドローン・コントロールLink | 個別契約に基づく提供 | Adapter Interface を通した外部制御（PX4、オリジナル制御等）との接続 | 機能の有効化・利用にはライセンスが必要 |
| 箱庭ドローン・シナリオLink | 個別契約に基づく提供 | 故障、外乱、センサノイズ、環境条件などを含む検証シナリオとの連携 | 機能の有効化・利用にはライセンスが必要 |
