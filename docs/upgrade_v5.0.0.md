# Hakoniwa Drone Simulator v4.2.0 → v5.0.0 アップデート手順

## はじめに

Hakoniwa Drone Simulator v5.0.0は、**センサモデル v2を標準にした**リリースです。センサの取り付け位置・
向き、ノイズの密度、ゆっくり変わるずれ、遅れ、測れる範囲、分解能などを、機体ごとに設定できます。

センサモデルが変わるため、**v4.2.0までの機体設定は、そのまま読めますが、同じ結果にはなりません（非互換）**。
v5.0.0で確かめた機体は`config/drone/x500-px4-sitl`です。それ以外の古いサンプルの機体設定は
[`legacy/`](../legacy/README.md)に移しました。`legacy/`は次の版で削除します。

既存のv4.2.0タグは変更しません。v5.0.0は新しいコミットとOS別バイナリとして配布します。

## 対象バージョン

- 更新元: `v4.2.0`
- 更新先: `v5.0.0`
- MuJoCo: `3.16.0`（変更なし）

v4.3.0は公開していません。v4.3.0での変更（バイナリログなど）も、この手順に含めます。

## 無償版の更新方法

v4.2.0と同じく、OS別バイナリをGitHub Releasesから取得します。

| ファイル | 対象環境 |
| --- | --- |
| `mac.zip` | macOS Arm |
| `lnx.zip` | Ubuntu 22.04 / 24.04 |
| `win.zip` | Windows 11 |

既存のv4.2.0ディレクトリへ上書きせず、v5.0.0を新しいディレクトリへ展開して設定を移行してください。
Dockerイメージも`v5.0.0`を使います。

## 非互換の変更

### センサモデル v2が標準になりました

センサ（加速度、ジャイロ、地磁気、気圧、GPS）の計算を、新しい仕様（センサモデル v2）に替えました。
v5.0.0からは、常にこのセンサモデルで動きます。仕様は[センサの共通仕様](architecture/aircraft/sensor/README.md)と、
センサごとの仕様にあります。

機体設定のセンサの書き方は、v1とv2の2つがあります。**今後はv2の書き方を推奨します。**

| 書き方 | 内容 | 動き |
| --- | --- | --- |
| v1の書き方 | v4.2.0までの項目だけで書いた設定 | 読めます。v1に近い動きになりますが、すべてが同じ仕様ではありません。一部の項目は使われません（下の表） |
| v2の書き方 | 取り付けの位置・向き（`mount`）、ノイズの密度、ずれ、遅れ、更新の周期、測れる範囲、分解能などを書いた設定 | センサを細かく設定できます。項目と単位はセンサごとの仕様を見てください |

v1の書き方のうち、v2では使われない項目です。読み込み時に`WARNING: unknown sensor setting`が出ます。
v2の書き方に書き換えてください。

| 項目 | 内容 | v2での書き方 |
| --- | --- | --- |
| `components.sensors.gps.eph`、`epv`、`sacc` | GPSが申告する精度（水平・垂直・速度） | [GPSの仕様](architecture/aircraft/sensor/gps/README.md)の精度の項目 |
| `components.sensors.gps.noise` | GPSの位置のノイズ | [GPSの仕様](architecture/aircraft/sensor/gps/README.md)のノイズの項目 |

**出力は、v4.2.0と同じにはなりません。** v1の書き方の設定でも、ノイズの乱数の引き方、計算の順番、
気圧とGPSの換算の式が変わるためです。ノイズのない設定でも、最下位の桁が変わることがあります。

`config/drone/x500-px4-sitl`は、v2の書き方に直してあります。書き換えの見本にしてください。

### 標準重力を9.80665 m/s²にしました

物理・制御・センサで使う重力加速度を、9.81から標準重力の9.80665 m/s²に揃えました。センサモデルと
関係なく、加速度と気圧の出力、制御の計算が、わずかに変わります。`config/controller/`の制御パラメータの
ファイルも、この値に揃えてあります。

### 古いサンプルの機体設定を`legacy/`に移しました

`api-1`、`mujoco-2`、`px4-1`、`ardupilot-1`などの古いサンプルは、v5.0.0では確かめていないため、
`legacy/config/drone/`に移しました。文書と起動の設定の参照先も`legacy/`に直してあります。
`legacy/`は次の版で削除します。詳しくは[`legacy/README.md`](../legacy/README.md)を見てください。

## そのほかの変更

### バイナリログ（v4.3.0から）

機体設定の`simulation.logging`に、次の項目を足しました。どれも省略でき、省略時はこれまでどおり
CSV・倍精度・全周期で書きます。

| 項目 | 値 | 内容 |
| --- | --- | --- |
| `mode` | `csv`（既定）、`binary`、`none` | `binary`はバイナリ形式（拡張子`.hblog`） |
| `precision` | `f64`（既定）、`f32` | `binary`のときだけ指定できます。単精度になるのは小数の列だけです |
| `interval_msec` | 1以上の整数（既定1） | ログを書く間隔（シミュレーション時刻、ms） |

`.hblog`をCSVに変換するツールは、箱庭ドローン PROに含まれます。`logging`に
知らない値を書くと、これまでは黙ってCSVとして扱っていましたが、v5.0.0では設定エラーで止まります。

### MAVLinkの操作ツール

`drone_api/mavlink_rpc`の操作ツールは、自動操縦のheartbeatだけを機体として扱うようになりました。
地上局などのheartbeatを機体のものと取り違え、飛行中なのに状態が`MAIN0`・disarmと表示されることが
なくなりました。

### そのほかの修正

- 移動の到着判定で、向きの差を±180°で折り返して比べるようにしました。
- 機体設定の`modelPath`（MuJoCoのモデル）を、ほかのファイルと同じく、機体設定のフォルダから先に探すように
  しました。
- `x500-px4-sitl`の脚の接触を、両端の4つの球にしました。高さマップの地面で脚が振動しにくくなります。

## 移行の手順

1. **v5.0.0を新しいディレクトリへ展開します。**
2. **機体設定を読ませます。** 読み込みのメッセージに`WARNING: unknown sensor setting`が出たら、
   その項目をv2の書き方に書き換えます（上の表）。警告がなくなるまで繰り返します。
3. **飛び方を確かめます。** 同じ飛行がそのまま再現されることは期待せず、離陸・ホバリング・移動・着陸を
   繰り返して、飛び方が変わっていないことを確かめます。
4. **制御のゲインを確かめ直します。** センサの誤差を変えたとき、または3で飛び方が変わったときは、
   制御のゲインを確かめ直してください。
5. **`legacy/`の機体を使っている場合**は、`config/drone/x500-px4-sitl`を元に機体設定を作り直すことを
   勧めます。`legacy/`は次の版で削除します。

## 更新後の確認項目

- `config/drone/x500-px4-sitl`でPX4 SITLが起動し、離陸・移動・着陸できること
  （[x500 PX4 SITLの手順](../config/drone/x500-px4-sitl/README.md)）。
- 機体設定に`logging`を書いていない場合、これまでどおりCSVのログが出ること。
