# 評価項目の定義（2026年10月版）

| # | 大分類 | 評価項目 | 評価する内容 |
|---:|---|---|---|
| 1 | A. コア性能 | 物理エンジンの種類と精度 | 利用可能な物理計算基盤と、実現象に対する妥当性を分けて見ます。 |
| 2 | A | 物理エンジンの拡張性 | 物理計算基盤や力学要素を交換・追加できるかを見ます。 |
| 3 | A | 機体特性の拡張性 | 質量、慣性、推力、battery等を設定できるかを見ます。 |
| 4 | A | 標準センサーの種類と精度 | センサーの種類、物理センサー、描画センサーを区別します。 |
| 5 | A | カスタムセンサーの拡張性 | 独自モデルの追加方法と独立実行の可否を見ます。 |
| 6 | A | 3D環境の再現度と拡張性 | 描画品質、自作自由度、衝突形状を区別します。 |
| 7 | A | 外部環境の拡張性 | 風、気圧、温度、障害物等を設定・注入できるかを見ます。 |
| 8 | B. 連携性 | FCの対応範囲 | PX4、ArduPilot、自作制御器との連携を見ます。 |
| 9 | B | 通信プロトコル | MAVLink等の標準プロトコルと独自通信の提供範囲を見ます。 |
| 10 | B | programming言語とAPI | 言語ごとのAPI、binding、RPCを同一視せず評価します。 |
| 11 | B | ROS/ROS 2 | ROS 1/2、トピック、サービス、アクション、QoSの対応範囲を見ます。 |
| 12 | B | 外部システムとの接続・連携手段 | ROS 2 Bridge、Client API、PDU、RPC、MCP等の接続・連携手段の有無を見ます。導入実績や公開事例の多寡は評価しません（2025年版「他システム連携実績」に対応）。 |
| 13 | C. 運用 | マルチビークル | 機体数に加えFC、物理計算基盤、プロセス、ホストの条件を見ます。 |
| 14 | C | 画面表示なしの高速化 | ビューアなしで実行できるかと速度を見ます。 |
| 15 | C | ログ・リプレイ | 通信データの再生と全内部状態の復元を区別します。 |
| 16 | C | 可視化の選択・分離 | コアとビューアの分離、別端末表示を見ます。 |
| 17 | C | 公式文書 | 網羅性、更新状況、版との対応、初学者導線を見ます。 |
| 18 | C | 開発者コミュニティ | 公開の活動度と利用者が質問できる場を見ます。 |
| 19 | C | 対応OS | 公式対応、OS固有対応、最善努力の対応を区別します。 |
| 20 | C | 要求ハードウェア | 最小構成、GPU要件、実測メモリを分けて見ます。 |
| 21 | C | モバイル・VR・AR | 標準対応と外部描画環境による構成を区別します。 |
| 22 | C | 構成要素の分離性 | 物理、制御、描画、通信を交換できるかを見ます。 |
| 23 | C | 地域言語サポート | 日本語資料・サポートとコミュニティ規模を区別します。 |
| 24 | C | 教育用途 | 導入容易性、見本、教材、学習負担を見ます。 |
| 25 | C | デモの視覚性 | 描画品質とinteractiveな操作を見ます。 |
| 26 | C | 独立ライブラリ利用 | コアを他のアプリケーションへ組み込めるかを見ます。 |
| 27 ★ | D. 検証性 | 決定論・反復再現性 | 同期実行、固定刻み、同じ結果の再現、ビット一致の実測を分けます。 |
| 28 ★ | D | センサー時間特性 | 更新周期、遅れ、雑音、ドリフト、精度、乱数の種を分けます。 |
| 29 ★ | D | 高速代役とSITLの応答照合 | 同じ機体モデルとあらかじめ決めた条件で制御の応答を比較し、基準と結果を再現可能に示せるかを見ます。軌跡の完全一致や実機との一致は意味しません。 |
| 30 ★ | D | 非実時間の処理性能 | 1飛行の実経過時間、実時間比、並列数を条件付きで見ます。 |
| 31 ★ | D | 故障注入と故障対応制御 | 物理への故障注入と制御器の対応を分けます。 |
| 32 ★ | D | パラメータ探索・回帰評価 | 自動探索、必須判定、得点、証跡、書き出しを見ます。 |
| 33 ★ | D | 実在都市データと遠隔操作 | PLATEAU/OSM等の生成とブラウザ操作を分けます。 |
| 34 ★ | D | 配布・再現可能な環境 | OS別パッケージ、コンテナ、構成記録等を見ます。 |
| 35 ★ | D | シナリオ標準連携 | OpenDRIVE、esmini、OpenSCENARIOの正式・試作段階を分けます。 |

★は2026年10月版で追加した項目です。
