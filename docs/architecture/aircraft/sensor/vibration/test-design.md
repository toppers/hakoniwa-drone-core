# プロペラ由来の IMU 振動：テスト設計

[振動の仕様](README.md) の `SEN-VIB-*` を、どの段で確かめるかを決めます。番号と種類は[センサ共通のテスト設計](../test-design.md)に従います。振動を有効にしたときに「飛び方が OFF と同じ」ことは、受け入れの条件にしません。

期待値は、実装の式を使い回さず、出力の波形を測って（DFT・RMS）、設定から別に計算した値と比べます。IMU のフィルタの期待値は、別の道具（`scipy.signal.cheby2`・`butter`）で設計した値です。試験は、生成器だけ（U1）→ IMU のフィルタだけ（F）→ 合わせたセンサ値（U2）の順に行います。

## 2. U1：式と位相（生成器だけ、1 ms の生の波形）

| 試験 | 入力 | 期待値 |
|---|---|---|
| T-VIB-U1-010 | 100 Hz（Ω = 200π rad/s）、Δt = 1 ms、回転の向き +1 と −1 | 1 ステップの位相の進みは 0.2π rad。−1 は逆向き |
| T-VIB-U1-020 | 100 Hz、`order` 1・2、軸ごとに違う振幅 | DFT で 100 Hz・200 Hz に、設定どおりの振幅（誤差 1e-9）。間の周波数は 0 |
| T-VIB-U1-030 | 回転数を基準の 2 倍 | 振幅が 4 倍（Ω² の設計の式。実機の物理の主張ではない） |
| T-VIB-U1-040 | 回っているロータを止める | 寄与は 0、位相は保たれる。回転数に上限がないこと（基準の 2 倍でもそのまま作る） |
| T-VIB-U1-050 | 同じ種・機体・ロータ・回転数の列を、2 つの生成器で。リセットしてもう一度。種なしも | すべてのサンプルが一致。機体の番号が違えば初めの位相も違う。種なしでもリセットで同じ波形 |
| T-VIB-U1-060 | 2 つのロータを 100 Hz と 110 Hz で 1 秒 | 合わせた値はロータごとの寄与の和。ロータごとの RMS はそれぞれの振幅から計算した値。回転数が違うので、合わせた RMS はロータごとの RMS の二乗和の平方根 |
| T-VIB-U1-070 | 物理 1 ms、最大の回転速度 1032 rad/s で、高調波 1・2・3（493 Hz）と 4（657 Hz）。6 次（986 Hz） | 3 次までは作れる。4 次・6 次は起動時のエラー（1 kHz で作ると約 14 Hz などに化けるため）。飛行中の回転数は制限しない |

## 3. U2：センサへの足し込み

| 試験 | 入力 | 期待値 |
|---|---|---|
| T-VIB-U2-010 | 振動の設定を省略・`enabled` false、同じ真値と種 | センサモデル v2 のセンサの出力・ノイズの列・ログが、ビット単位で一致 |
| T-VIB-U2-020 | 加速度とジャイロに、1 ステップの同じ振動のサンプルを渡す | 生成器の位相は 1 回しか進まない。両方が同じ時刻の値を読む |
| T-VIB-U2-030 | 真の ω = 0・α = 0、r ≠ 0、振動の角速度だけ 0 でない | ジャイロだけ変わる。α×r と ω×(ω×r) は変わらない |
| T-VIB-U2-040 | IMU のヨー 90°、FRD の振動、センサの誤差を順に有効にする | 手計算の Rᵀ と、感度・遅れ・測る・分解能・頭打ちの順に合う |
| T-VIB-U2-050 | 種を固定してリセット。ほかのセンサのノイズの設定だけ変える | 振動の列はリセット後も一致し、ほかの特性の乱数の消費に影響されない |
| T-VIB-U2-060 | 加速度・ジャイロに IMU のフィルタを有効にし、真値の正弦波（たとえば 5 Hz）だけを入れる | 出力の振幅と位相の遅れが、フィルタの設計の値に一致する（制御の遅れが増えることを確かめる） |
| T-VIB-U2-070 | 真値（低い周波数）＋振動（93 Hz・186 Hz）を IMU に入れ、IMU のフィルタのあと 4 ms で測る | 186 Hz の折り返し（63.6 Hz）が、振動の振幅の 1% 未満。93 Hz は設計の利得。真値の成分は設計の利得と遅れで出る |

## 4. F：IMU のフィルタの受け入れ試験（共通仕様 4.5）

フィルタだけを、真値も振動もない形で確かめます。振動を有効にした閉ループの試験（I2・S）は、この章と U2 の試験に合格した構成で行います（`SEN-VIB-178`）。

| 試験 | 入力 | 期待値 |
|---|---|---|
| T-VIB-F-010 | Chebyshev II、物理 1 kHz、阻止域の端 125 Hz。次数・減衰を (6, 40 dB)・(8, 60 dB)・(4, 30 dB) | 10〜400 Hz の 10 点の利得が、`scipy.signal.cheby2` の設計と 1e-4 dB 以内。125〜500 Hz のすべてで、利得 ≦ −減衰 |
| T-VIB-F-020 | Butterworth、物理 1 kHz、次数・−3 dB を (2, 100 Hz)・(4, 80 Hz) | 10〜400 Hz の利得が、`scipy.signal.butter` の設計と 1e-4 dB 以内。−3 dB の点がその周波数 |
| T-VIB-F-030 | (6, 40 dB) の Chebyshev II と (2, 100 Hz) の Butterworth に、5・50・93.2・164・186 Hz の正弦波を通す | 過渡のあとの振幅（DFT で測る）が、設計の利得に一致 |
| T-VIB-F-040 | 同じ 2 つのフィルタに 5 Hz・20 Hz の正弦波 | 出力の位相の遅れ（DFT で測る）が、設計の位相（`scipy.signal.sosfreqz`）に一致。遅い動きの遅れ（ms）を記録する |
| T-VIB-F-050 | 次数が奇数、周波数が物理のナイキスト周波数以上、減衰が 0 以下、種類が違う | 設計・読み込みでエラー |
| T-VIB-F-060 | 振動を有効にし、4 ms で読む。(6, 40 dB)・端 125 Hz のフィルタ。端を 130 Hz にしたもの。フィルタなし | 125 Hz は作れる。130 Hz（ナイキストから 130 Hz までが −40 dB に届かない）とフィルタなしは起動時のエラー |
| T-VIB-F-070 | フィルタを書かない加速度・ジャイロ | 出力がこれまでの v2 とビット単位で同じ |

## 5. U3：設定

| 試験 | 入力 | 期待値 |
|---|---|---|
| T-VIB-U3-010 | ブロックの省略、false、true | OFF は生成器を作らない。true は必須の項目がそろっているときだけ作る |
| T-VIB-U3-020 | 足りない、未知の `model`、`referenceRpm` ≦ 0、`harmonics` が空、同じ `order`、0 以下・小数の `order`、振幅が 2 つ、未知の設定、`antiAliasFilter` がない・種類が違う・`order` が小数・未知の設定 | 有効なときはエラー。v2 なしのビルドや、回転数のないモードで有効にしたときもエラー |

## 6. I1：実際のロータとのつなぎ込み

| 試験 | 条件 | 期待値 |
|---|---|---|
| T-VIB-I1-010 | ロータを一定の回転数で回す | ロータの実際の角速度と、振動の基本波の周波数が一致。Duty の値ではなく、回転の遅れを反映する |
| T-VIB-I1-020 | 1 基を故障させ、実際の回転数が 0 へ下がる | そのロータの波形だけが、回転数に追って小さくなり、消える |
| T-VIB-I1-040 | 振動を有効にしたログ | シミュレーションの時刻で、実際の回転数、生の波形、フィルタのあと、センサの最終の値を分けて照合できる |

## 7. I2・S：制御と自動操縦（F の合格が前提）

| 試験 | 条件 | 期待値 |
|---|---|---|
| T-VIB-I2-010 | PX4・ArduPilot の Control Link。同じ機体・PID・ミッションで、振動の OFF・ON | IMU の PSD・RMS（ロータごとと合わせたもの）、EKF のイノベーション、推定、制御の結果を比べ、差を記録する。必ず悪くなるとは決めない |
| T-VIB-S-010 | PX4 SITL（4 ms の HIL_SENSOR） | PX4 に届く振動が、フィルタの設計どおりの帯域と減衰になっている |
| T-VIB-S-020 | ArduPilot SITL | 箱庭の振動を送らない（二重にしない）。`SIM_VIB_*` の実験とは分けて記録する |

## 8. レビューと実機での同定

- **R-VIB-01**：振幅は FRD でのセンサの観測の振幅で、偏りの力（N）をそのまま IMU の m/s²・rad/s として使っていないか。
- **R-VIB-03**：Control Link・PX4 SITL・ArduPilot SITL で、振動を誰が作るかを記録し、二重に足していないか。
- **R-VIB-04**：ArduPilot の GPL のコードを写さず、一般的な式から独立に作っているか。
- **R-VIB-05**：振幅が仮の値であることを、設定の例・記録・報告に書いているか。実機の特性と言っていないか。
- **実機での同定**：高い速さの IMU と、実際の回転数と、フィルタの設定を、ホバー・回転数の掃引・前進で取ります。係数を決める区間と、PSD・RMS・ピークを照合する区間を分けます。実機のログがないあいだは、数式とソフトウェアの上での確認と書きます。
