# ジャイロのテスト設計

[ジャイロの仕様](README.md) の要求（`SEN-GYR-*`）を、どこで確かめるかを決めます。
確かめ方の種類・判定の基準・試験の番号の決まりは、[センサのテスト設計（共通）](../test-design.md) のとおりです。

## 1. 要求の確かめ方

| 要求 | 段 | 試験 | 確かめること |
|---|---|---|---|
| SEN-GYR-010 | U2 | T-GYR-U2-010 | 入力の軸と単位、出力の軸と単位（符号が分かる例） |
| SEN-GYR-020 | U2 | T-GYR-U2-020 | `yaw = 90` で、機体のロールの回転がセンサの −y に出る |
| SEN-GYR-030 | U2 | T-GYR-U2-030 | 取り付けの位置を変えても出力が変わらない |
| SEN-GYR-040 | U2 | T-GYR-U2-040、T-GYR-U2-050 | 順番で結果が変わる例で、仕様の順番の結果になる |
| SEN-GYR-050 | U2、U3 | T-GYR-U2-060、T-GYR-U3-010 | σ の実測。1 つの値と [x, y, z]。0 以下の軸はノイズなし |
| SEN-GYR-060 | U2 | T-GYR-U2-070 | 三角波の値（独立に計算した時刻ごとの値）、3 軸に同じ量 |
| SEN-GYR-070 | U2 | T-GYR-U2-080 | 酔歩の分散が時間に比例して増える、3 軸が独立、`seed` で再現 |
| SEN-GYR-080 | U2 | T-GYR-U2-090 | 分散が σ²、遅れ τ の自己相関が e⁻¹（共通の 4.2） |
| SEN-GYR-090 | U2 | T-GYR-U2-100 | `yaw = 90` で付けたとき、ドリフトがセンサの軸に乗る（機体の軸では回った向きに見える） |
| SEN-GYR-100 | U2 | T-GYR-U2-110 | 範囲の内・ちょうど・外。分解能のあとに切る |
| SEN-GYR-110 | U2 | T-GYR-U2-120 | 斜めに付けると、機体の軸では範囲内でもセンサの軸で振り切れる |
| SEN-GYR-120 | R | R-03 | 振り切れたことを、出力・ログ・自動操縦への値のどこにも出していない |
| SEN-GYR-130 | U2 | T-GYR-U2-130 | 目盛りの誤差・軸の干渉の手計算の例。姿勢で回したあとに掛かる |
| SEN-GYR-140 | U2 | 既定値の互換 | `sensitivity` を省略すると出力が変わらない |
| SEN-GYR-150 | U2 | T-GYR-U2-140 | 決まったずれが、軸ごとにそのまま足される |
| SEN-GYR-160 | U2 | T-GYR-U2-150 | 多くの種で起動時のずれを集め、平均 0・σ が設定どおり。1 回の飛行の中では変わらない |
| SEN-GYR-170 | U3 | T-GYR-U3-020 | 両方を書くとエラー。省略でずれなし |
| SEN-GYR-180 | U2 | T-GYR-U2-140、T-GYR-U2-150 | 時間がたっても、ゼロ点のずれが変わらない |
| SEN-GYR-190 | U1 | 共通の丸めの関数の試験 | 最も近い刻みに丸める。頭打ちの前に当たる（T-GYR-U2-110） |
| SEN-GYR-200 | U1 | 共通の丸めの関数の試験 | ちょうど中間（±0.5 刻み）は 0 から遠い方 |
| SEN-GYR-210 | U2 | 既定値の互換 | 省略すると丸めない |
| SEN-GYR-220 | I2、S | T-GYR-I2-010、T-GYR-S-010 | 回して付け、自動操縦にも合わせて飛ぶ（共通の 4.3） |
| SEN-GYR-230 | U1、R | T-GYR-U1-010、R-04 | ArduPilot SITL の起動の設定で `SIM_IMU_ORIENT` = 0 |
| SEN-GYR-240 | U1、R | T-GYR-U1-010、R-04 | 同じく `SIM_GYR1_RND` = 0 |
| SEN-GYR-250 | U1 | T-GYR-U1-020 | 置き換えの項目（`SIM_GYR1_BIAS`・`SIM_DRIFT_*`・`SIM_GYR1_SCALE`）の変換の手計算の例。置き換えたものは箱庭の側で足していない |

仕様の 6 章「受け入れの確かめ方」との対応は次のとおりです。

| 受け入れ | 試験 |
|---|---|
| 1. 既定値の互換 | 共通の 4.4（T-GYR-U2-160） |
| 2. 回転の式 | T-COM-U1-010、T-COM-U1-020、T-COM-U1-110、T-COM-U1-120 |
| 3. 飛行 | T-GYR-I2-010、T-GYR-S-010 |
| 4. 軸ごとの頭打ち | T-GYR-U2-120 |

## 2. 試験の一覧

### 2.1 センサの単体試験（U2）

| 試験 | 入力 | 期待値 | 要求 |
|---|---|---|---|
| T-GYR-U2-010 | ω_body = (0.1, −0.2, 0.3) rad/s、取り付けなし、誤差なし | ω_sensor = (0.1, −0.2, 0.3) | 010 |
| T-GYR-U2-020 | `yaw = 90`、ω_body = (1, 0, 0) rad/s | ω_sensor = (0, −1, 0) | 020 |
| T-GYR-U2-030 | `positionM` を (0, 0, 0) と (0.3, −0.2, 0.1) で比べる | 同じ値 | 030 |
| T-GYR-U2-040 | 範囲 ±250°/s、`yaw = 45`、ω_body = (200, 200, 0)°/s | センサの x が約 283°/s → 250 で切れる（回してから切る） | 040、110 |
| T-GYR-U2-050 | 刻み 10°/s、範囲 ±245°/s、入力 248°/s | 分解能で 250 → 頭打ちで 245（丸めてから切る） | 040、100、190 |
| T-GYR-U2-060 | σ = [0.01, 0.02, 0] rad/s、N = 20,000 | x・y の σ が設定の ±3%、z はノイズなし、x と y の相関 < 0.03 | 050 |
| T-GYR-U2-070 | `ardupilot-sitl`、速さ 0.5°/s/分、周期 5 分 | 0・2.5・5・7.5・10 分での値が三角波の手計算の値。3 軸に同じ | 060 |
| T-GYR-U2-080 | `random-walk`、密度 0.01°/s/√s、`seed` 固定、多数の種 | 時刻 t の分散が 密度²·t に比例（±10%）。同じ `seed` で同じ並び | 070 |
| T-GYR-U2-090 | `gauss-markov`、σ = 0.005°/s、τ = 0.1 s | 共通の 4.2 の判定 | 080 |
| T-GYR-U2-100 | `yaw = 90`、決まった大きさのドリフトだけ（ほかの誤差なし） | ドリフトがセンサの軸に乗る。機体の軸に戻すと 90° 回った向き | 090 |
| T-GYR-U2-110 | 範囲 ±250°/s に −300・−250・0・250・300°/s | −250・−250・0・250・250 | 100 |
| T-GYR-U2-120 | 範囲 ±250°/s、`yaw = 45`、ω_body = (200, 200, 0)°/s（機体の軸ではどれも範囲内） | センサの x だけ 250 で切れる | 110 |
| T-GYR-U2-130 | `scaleErrorPct` = [1, 0, 0]、`crossAxisPct[1][0]` = 2、`yaw = 90` | 手計算の値（回してから M を掛けた値） | 130 |
| T-GYR-U2-140 | `fixedDegPerSec` = [0.5, −1.0, 0.2]、ω_body = 0、長い時間 | 出力が (0.5, −1.0, 0.2)°/s のまま変わらない | 150、180 |
| T-GYR-U2-150 | `randomStdDegPerSec` = 1.0、20,000 個の種 | 起動時のずれの平均 0（共通の 4.2）、σ が ±3%。1 回の中では変わらない | 160、180 |
| T-GYR-U2-160 | 新しい項目を書かない既存の設定 | 変更の前後で出力がビット単位で一致（共通の 4.4） | 140、210 ほか |

### 2.3 関数の単体試験（U1）

| 試験 | 入力 | 期待値 | 要求 |
|---|---|---|---|
| T-GYR-U1-010 | ArduPilot SITL の起動の設定を作る | `SIM_IMU_ORIENT` = 0、`SIM_GYR1_RND` = 0 | 230、240 |

### 2.4 飛行の試験（I2・S）

判定は共通の 4.3 のとおりです。基準の飛行と試す飛行をそれぞれ 5 回以上飛ばし、差の 95% 信頼区間を許せる差 δ（共通の 4.3.1 の既定値）と比べます。

| 試験 | 動かし方 | 基準の飛行 | 試す飛行 | 判定 | 要求 |
|---|---|---|---|---|---|
| T-GYR-I2-010 | Control Link（PX4、ArduPilot） | 取り付けなし、ホバーと四角の経路 | IMU を `yaw = 90` で付け、自動操縦にも同じ姿勢 | 同じように飛ぶ | 220、COM-270、COM-340、COM-350 |
| T-GYR-I2-020 | 同上 | 同上 | IMU を `yaw = 90` で付け、自動操縦には合わせない | ずれる（または飛べない） | 220、COM-270 |
| T-GYR-S-010 | PX4 SITL、ArduPilot SITL | 同上 | 同 T-GYR-I2-010 | 同じように飛ぶ | 220、COM-270 |
| T-GYR-S-020 | 同上 | 同上 | 同 T-GYR-I2-020 | ずれる（または飛べない） | 220、COM-270 |

- 指標：位置の誤差の二乗平均（目標の経路から）、姿勢の誤差の最大、離陸から着陸までにかかった時間。
- 「ずれる」側の試験（I2-020、S-020）は、合わせる設定が本当に効いていることを確かめるためのものです。
  回して付けたまま合わせないと、機体はふつう離陸の直後に姿勢を保てなくなります。その場合は「飛べない」を合格とします。
