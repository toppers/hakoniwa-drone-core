# GPS のテスト設計

[GPS の仕様](README.md) の要求（`SEN-GPS-*`）を、どこで確かめるかを決めます。
確かめ方の種類・判定の基準・試験の番号の決まりは、[センサのテスト設計（共通）](../test-design.md) のとおりです。

## 2. 試験の一覧

### 2.1 関数の単体試験（U1）

換算の期待値は、仕様の式をなぞらずに作ります。
別の計算として、原点を地心直交座標（ECEF）に直し、原点での北・東の向きの変位を足して、緯度・経度・高度へ戻します（GeographicLib、PROJ など）。
この計算は平らとみなす近似を使わないので、仕様の近似の誤差まで含めて比べられます。比べる量は、2 点の間の距離（測地線の長さ、m）です。
原点の経度は 139°、原点の高度は 0 m と 1,000 m の両方で行います。

### 2.5 飛行の試験（I2・S）

判定は共通の 4.3 のとおりです。基準の飛行と試す飛行をそれぞれ 5 回以上飛ばし、差の 95% 信頼区間を許せる差 δ と比べます。
δ は、表に書いたもの以外は共通の 4.3.1 の既定値です。

ArduPilot SITL は、水平の位置のノイズとドリフトを再現できません（仕様 6 章）。そのため、位置のノイズ・ドリフトを入れる飛行の試験は、Control Link と PX4 SITL だけで行います。
PX4 SITL には速度の精度が渡らない（HIL_GPS に欄がない）ので、PX4 SITL で合わせる精度の申告は位置の精度までです。

| 試験 | 動かし方 | 基準の飛行 | 試す飛行 | 判定 | 要求 |
|---|---|---|---|---|---|
| T-GPS-I2-010 | Control Link（PX4、ArduPilot） | GPS の誤差なし、ホバーと四角の経路 | `positionNoise` = 水平 0.3・垂直 0.5 m、`velocityNoise` = 水平 0.1・垂直 0.2 m/s、`delayMsec` = 150。自動操縦の見込み（6 章）と精度の申告（4.2）を合わせる | 同じように飛ぶ。位置の誤差の δ = 0.15 m | 250、300、COM-300 |
| T-GPS-I2-020 | 同上 | 同上 | `drift` = 水平 1 m・垂直 2 m、τ = 120 s。精度の申告を水平 1 m・垂直 2 m に合わせる | 同じように飛ぶ。位置の誤差は「GPS で見た位置の誤差」で測り、δ = 0.1 m | 200、220、250 |
| T-GPS-I2-030 | 同上 | 同上 | GPS を `positionM` = [0.3, 0, −0.2] に付け、自動操縦にも同じ位置（重心から見た値）を設定 | 同じように飛ぶ | 100、130、COM-280、COM-290 |
| T-GPS-S-010 | PX4 SITL | 同上 | 同 T-GPS-I2-010 | 同じように飛ぶ。位置の誤差の δ = 0.15 m | 260、300、COM-300 |
| T-GPS-S-020 | PX4 SITL | 同上 | 同 T-GPS-I2-020 | 同じように飛ぶ。位置の誤差は「GPS で見た位置の誤差」で測り、δ = 0.1 m | 200、220、260 |
| T-GPS-S-030 | PX4 SITL、ArduPilot SITL | 同上 | 同 T-GPS-I2-030（ArduPilot SITL では `SIM_GPS_POS_*` と `GPS1_POS_*`） | 同じように飛ぶ | 290、COM-280、COM-290 |
| T-GPS-S-040 | ArduPilot SITL | — | 地上に止めたまま、`velocityNoise` の垂直 = 0.2 m/s（水平は 0）、`SIM_GPS_HZ` = 10、600 秒（N = 6,000）。起動から 30 秒は捨てる。間引かない | ArduPilot のログ `GPS.VZ`（GPS の生の値）の σ が 0.2 m/s の ±5%（N = 6,000 で σ の推定の標準誤差は約 0.9%、±5% は約 5.5 倍）。`SIM_GPS_VERR_Z` = 0.2·√3 から一様分布の σ に戻ることの確認。北・東は記録に別々の成分がないので、U1 の手計算で確かめる | 320 |

- 指標：位置の誤差の二乗平均（目標の経路から）、姿勢の誤差の最大、離陸から着陸までにかかった時間。
- I2-010・S-010 の δ = 0.15 m の理由：毎回ばらばらのノイズは EKF でならされるので、真の位置の誤差の増え方は、ノイズの水平 σ（0.3 m）より十分小さいはずです。
  σ の半分を超えて増えるなら、推定がノイズを追っている（見込みや精度の申告が合っていない）と判断します。
- I2-020・S-020 の「GPS で見た位置の誤差」は、GPS の出力の位置（m に戻した値）と目標の経路の差です。
  ドリフトがあると、自動操縦は GPS の位置に従って飛ぶので、真の位置は設計どおりドリフトの分（約 1〜2 m）ずれます。このずれは推定の安定とは関係がないので、GPS の位置で測ります。
  ノイズは 0 なので、この誤差は経路への追従の誤差だけになります。
- I2-020・S-020 の δ = 0.1 m の理由：τ = 120 s、σ = 1 m のドリフトは、1 秒で約 0.13 m（σ·√(2Δt/τ)）しか動きません。推定は追いつくので、追従の誤差の増え方は小さいはずです。
  既定の 0.05 m では、ドリフトを追うわずかな遅れまで落とす恐れがあるので、0.1 m にします。
- I2-030・S-030 は、アンテナの位置が効くのは主に回ったときの速度と、傾いたときの位置です。合わせれば、原点に付けたときとほぼ同じように飛ぶことを確かめます。
- GPS に誤差があると、自動操縦は GPS を使い始めたときの値で原点を決めるので、推定の原点が真値と少しずれ、飛行中ずっと残ります（本物の機体でも起きます）。
  そこで、I2・S の GPS の試験では、次のように測ります。
  - 「着いた」の判定は、自動操縦の推定の位置で行います（本物のミッションと同じ）。
  - 原点のずれ（離陸の指令の直前 0.5 秒の、推定の位置 − 真の位置の平均の水平の大きさ）を、別の指標として報告します。判定には使いません。
  - 位置の誤差の二乗平均は、真の位置に原点のずれを足して（推定の座標にそろえて）、目標の経路と比べます（経路を追いかける誤差）。
- 飛行のログで、自動操縦が読んだパラメータ（`SENS_GPS0_DELAY`、`GPS1_DELAY_MS`、`SENS_GPS0_OFF*`、`GPS1_POS_*`、`SIM_GPS_*`）の値を確かめます（共通の SEN-COM-300）。
