# 加速度センサのテスト設計

[加速度センサの仕様](README.md) の要求（`SEN-ACC-*`）を、どこで確かめるかを決めます。
確かめ方の種類・判定の基準・試験の番号の決まりは、[センサのテスト設計（共通）](../test-design.md) のとおりです。

この文書の数値は、g₀ = 9.80665 m/s²（標準重力、仕様 1 章。MuJoCo の重力・1 g の換算も同じ）（単位の換算、仕様 3 章）を使い分けて手で計算しています。
「水平に止まっている」は、機体の姿勢が水平で、機体の原点の並進加速度 a = 0、角速度 ω = 0、角加速度 α = 0 のことです。

### 2.4 機体の試験（I1）

MuJoCo で機体を動かし、センサの出力を物理の答えと比べます。比べる相手として、MJCF の IMU の取り付けの位置に site を置き、
MuJoCo の加速度センサ（`accelerometer`）をその site に付けます。MuJoCo の軸（前・左・上）は FRD に直して比べます。
ノイズ・ずれ・目盛りの誤差・分解能・頭打ちは、すべてなしにします。
site の加速度センサは、箱庭の実装が値を作るのに使わないもの（試験の側だけが読むもの）とします。さらに I1-030・I1-040 は、試験の側で、MuJoCo の機体の本体の並進加速度・角速度・角加速度と既知の r から剛体の式で求めた値とも一致することを確かめます（期待値を 2 つの独立した仕組みで作る）。

| 試験 | 入力 | 期待値 | 幅 | 要求 |
|---|---|---|---|---|
| T-ACC-I1-010 | 平らな地面に、水平に置いて止めた機体（モーターは止める） | (0, 0, −9.80665) | 0.01 m/s²（接触の揺れを見込む） | 010、020 |
| T-ACC-I1-020 | 空中で速度 0 から放した機体（モーターは止める、空気の抵抗なし） | (0, 0, 0) | 1e-6 m/s² | 020 |
| T-ACC-I1-030 | 重力の効かない状態（自由落下。加速度センサにも MuJoCo の site の加速度計にも重力の加速度は現れない）、空気の抵抗なしで、z の軸のまわりに 300°/s で回し続ける機体（角加速度 0）。IMU は r = (0.05, 0, 0) m | 同じ時刻の IMU の値 − 原点の値 = (−1.3708, 0, 0)。site の `accelerometer` の値と一致 | 1e-6 m/s² | 040 |
| T-ACC-I1-040 | 重力の効かない状態（自由落下）で、回っていない機体に z の軸のまわりのトルクを与えた最初の刻み。IMU は r = (0.1, 0, 0) m | 同じ時刻の IMU の値 − 原点の値 = α × r（α は MuJoCo の角加速度。α = (0, 0, 10) rad/s² になるトルクなら (0, 1.0, 0)）。site の `accelerometer` の値と一致 | 1e-6 m/s² | 040 |

### 2.5 飛行の試験（I2・S）

判定は共通の 4.3 のとおりです。基準の飛行と試す飛行をそれぞれ 5 回以上飛ばし、差の 95% 信頼区間を許せる差 δ と比べます。

| 試験 | 動かし方 | 基準の飛行 | 試す飛行 | 判定 | 要求 |
|---|---|---|---|---|---|
| T-ACC-I2-010 | Control Link（PX4、ArduPilot） | 取り付けなし。ホバー、前後・左右・斜めの移動と、その場でヨーを 179° 回す経路（自動操縦の既定の速さ・ヨーの速さ） | IMU を `positionM` = [0.10, 0.00, 0.00] で付け、自動操縦にも IMU の位置（重心から）を設定 | ほぼ同じように飛ぶ（δ は下の表） | COM-280、COM-290、COM-300、250 |
| T-ACC-S-010 | PX4 SITL、ArduPilot SITL | 同上 | 同上 | 同上 | COM-280、COM-290、COM-300、250、260 |

「ほぼ同じように飛ぶ」の許せる差 δ は、試験を走らせる前に、物理として残る差の見積もりから次のように決めます。

| 指標 | δ | 理由 |
|---|---|---|
| 位置の誤差の二乗平均 | 既定値（0.05 m と、基準の平均の 10% の大きい方） | 残る加速度は、ヨーの回転中の中心へ向かう加速度 (π/2)² × 0.10 ≈ 0.25 m/s² と、回り始め・止まりの α × r。GPS で直すまで（0.2 s 程度）に積もる位置のずれは ½ × 0.25 × 0.2² ≈ 0.005 m で、既定値より 1 けた小さい |
| 姿勢の誤差の最大 | 1.5° | 0.25 m/s² の加速度を、推定が重力の向きのずれと受け取ったときの傾き atan(0.25 / 9.81) ≈ 1.5° を上限とする。既定値の 1° では、この物理の差で落ちることがある |
| かかった時間 | 既定値（0.5 秒） | 経路と速さは同じなので、位置の加速度で時間は変わらない |

- 「同じように飛ぶ」だけでは、位置の加速度が値に入っていなくても通ってしまいます。そこで、その場でヨーを回している間（その場の回転の指令から、
  次の移動の指令までの区間。到着はヨーではなく位置で判定されるので、到着の時刻では区切らない）について、
  センサの x の平均が、真の角速度 ω から求めた中心へ向かう加速度の平均 −ω² × 0.10 と ±0.02 m/s² で合うことを、試す飛行で確かめます
  （基準の飛行では、同じ区間のセンサの x の平均が 0 ± 0.02 m/s²）。ヨーの速さは自動操縦の既定の値なので、残る加速度は上の表の 0.25 m/s²
  （90°/s のとき）より小さく、δ は上の表のままでよい（大きい側の見積もり）。
  ArduPilot SITL では、仕様 5 章のとおり ArduPilot SITL が軸ごとに約 ±0.01 m/s² の一様なノイズを足します（標準偏差 約 0.0058 m/s²）。
  平均を取る値なので、この幅 ±0.05 m/s² の中に収まります。ArduPilot SITL の加速度の値でノイズの大きさを測る試験では、箱庭の σ にこの分（分散 0.01²/3）を足して判定します。
- 自動操縦が読んだ IMU の位置の値（重心から見た値）を、飛行のログで確かめます（COM-290、COM-300）。
- 姿勢を合わせる・合わせない飛行（受け入れの 6）は、ジャイロの T-GYR-I2-010・020、T-GYR-S-010・020 で確かめます。
